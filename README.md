## 🎓 Acerca del Bootcamp

**Undefined Academy** es un bootcamp intensivo de desarrollo web Full-stack con JavaScript. Nuestro programa está diseñado para equiparte con las habilidades necesarias para convertirte en un desarrollador Full-stack, mientras te conectas con una comunidad apasionada de profesionales y entusiastas.

### Instructor

El bootcamp es impartido por **Guillermo Rodas**, un desarrollador Full-stack en JavaScript con más de una década de experiencia:

- Organizador de CSS Community Dev y CSS Conf Colombia
- Google Developer Expert en Tecnologías Web
- Auth0 Ambassador y Twitch Partner
- Profesor de 6 cursos en Platzi
- Coach técnico del programa Platzi Master por más de 2 años
- Mentor del Bootcamp Full-stack con World Tech Makers
- Más de 50 charlas en diferentes meetups y conferencias

## 📚 Contenido del Programa

El bootcamp cubre un currículo completo que incluye:

### Fundamentos
- Introducción a la programación (código, algoritmos, sentencias, expresiones y operadores)
- Configuración del ambiente de desarrollo (Ubuntu, Git, Node.js, Yarn, VS Code)
- Fundamentos de Markdown y uso de la terminal
- Control de versiones con Git
- Introducción a HTML y CSS

### Frontend
- Flexbox y CSS Grid
- Responsive Design
- Estructura moderna de proyectos (Webpack, Vite)
- Frameworks de UI (Bootstrap 5, Tailwind CSS)
- Librerías de JavaScript (Lodash, Day.js)
- React y Next.js

### JavaScript Avanzado
- ES2015+ y nuevas características del lenguaje
- Programación asíncrona (callbacks, promesas, async/await)
- Closures y herencia de prototipos
- Programación funcional
- JavaScript en producción (Babel, minificación, Source maps, Code Splitting)

### Backend
- Introducción a Node.js y servidores
- Express.js
- MongoDB y Mongoose
- Autenticación con Passport.js
- Seguridad Web (injection, autenticación, protección de datos sensibles)

### Testing
- Unit testing
- Snapshot testing en React
- Tests funcionales
